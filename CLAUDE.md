# Долина Эникей — заметки для Claude

Учебный 3D-тренажёр по Python для школьников 11–14 лет. Интерфейс и все тексты — на русском.
Ученик пишет код в редакторе, герой выполняет его в 3D-мире, каждое решение проверяется на трёх случайных картах.

## Устройство
- Сборки нет: чистые HTML/CSS/JS, скрипты подключаются тегами `<script>` в `index.html`, без модулей и npm-зависимостей.
- `js/three.min.js` — three.js r128 (UMD, глобальный `THREE`). Не обновлять без необходимости: в r128 нет CapsuleGeometry.
- `js/minipy.js` — свой интерпретатор подмножества Python (генераторы, пошаговое выполнение). Ошибки — `PyError` с понятным русским текстом и номером строки. Имена нормализуются: `ё` → `е` (`вперёд` и `вперед` — одно и то же).
- `js/world.js` — логика мира и массив `TASKS`. Команды героя — генераторы, которые меняют состояние и `yield`-ят события для анимации (`move`, `turn`, `jump`, `take`, `check`, `bump`, `burn`, `win` …). Провал — `WorldError` с полем `kind`, победа — `WinSignal`.
- `js/app.js` — three.js-сцена, анимация событий, редактор с подсветкой, звёзды, подсказки, прогресс в localStorage (ключ `mir-geroya-usloviya-v1`, не менять, иначе ученики потеряют прогресс).

## Правила для новых заданий
- Карта должна меняться от сида так, чтобы решение «под одну карту» ломалось, а решение с условием работало всегда.
- Стартовый код ломается, `hints[2]` — эталонное решение, `best` — число строк для третьей звезды.
- Новую команду героя добавить в `commands()` (world.js), в `HERO_CMDS` (app.js) для подсветки и, если нужно, анимацию в `animate()`.
- Тексты для детей: коротко, на «ты», без канцелярита.

## Проверка
`node tests/check-tasks.js` — для каждого задания на 40 сидах решение проходит все карты, стартовый код ломается. Запускать после любых изменений в заданиях, minipy.js или world.js.

## Публикация
GitHub Pages из ветки `main`, корень репозитория. После слияния изменений в `main` сайт обновляется сам.
