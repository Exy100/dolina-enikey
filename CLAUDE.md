# Долина Эникей — заметки для Claude

Учебный 3D-тренажёр по Python для начинающих с 12 лет. Интерфейс и все тексты — на русском.
Это инструмент репетитора: занятия 1 на 1 онлайн, ученик показывает экран. Концепция, сценарий часа, работа с клиентами (Авито) и план — в `PLAN.md`, сверяйся с ним.
Ученик пишет код в редакторе, герой выполняет его в 3D-мире. Курс — 7 уроков по 8 заданий: «Команды», «Циклы» (у задания одна нарисованная карта), «Условия», «Цикл while», «Переменные», «Функции», «Лабиринт» (каждое решение проверяется на трёх случайных картах).

## Устройство
- Сборки нет: чистые HTML/CSS/JS, скрипты подключаются тегами `<script>` в `index.html`, без модулей и npm-зависимостей.
- `js/three.min.js` — three.js r128 (UMD, глобальный `THREE`). Не обновлять без необходимости: в r128 нет CapsuleGeometry.
- `js/minipy.js` — свой интерпретатор подмножества Python (генераторы, пошаговое выполнение). Ошибки — `PyError` с понятным русским текстом и номером строки. Имена нормализуются: `ё` → `е` (`вперёд` и `вперед` — одно и то же). Есть `def` с параметрами и `return`: внутри приёма свои переменные, внешние можно читать, но не менять (понятная ошибка). Свой приём с именем команды заменяет её — так в лабиринте чинят «сломанный» `turn_right()`.
- `js/world.js` — движок мира: команды героя, карты (`fromAscii`, `corridor`, `pickLava`), `LESSONS` и `addLesson`. Команды героя — генераторы, которые меняют состояние и `yield`-ят события для анимации (`move`, `turn`, `jump`, `take`, `check`, `bump`, `burn`, `win` …). Провал — `WorldError` с полем `kind`, победа — `WinSignal`.
- `js/lessons/N-id.js` — по файлу на урок, вызывают `HeroWorld.addLesson({ id, title, intro, basic, tasks })`. Порядок уроков — порядок `<script>` в `index.html`; тест проверяет, что каждый файл подключён. `basic: true` — урок без условий: у задания `map` (карта-рисунок, одна), в сообщениях об ошибках нет советов про `if`/датчики, а флаг засчитывается только в конце программы — шаг или прыжок с флага даёт ошибку `extra` («лишние команды»). Поэтому если последний повтор цикла кончается `взять()`, на флаге тоже лежит монета (`@` на карте). Уроки с условиями используют `gen` (три случайные карты).
- `js/app.js` — three.js-сцена, анимация событий, редактор с подсветкой, выбор урока, звёзды, подсказки, прогресс в localStorage (ключ `mir-geroya-usloviya-v1`, не менять, иначе ученики потеряют прогресс). Прогресс ключуется по `id` задания, поэтому `id` уникальны во всём курсе и не переименовываются; текущий урок и задание — `save.lesson` и `save.pos`; надетые вещи — `save.gear`, показанные реплики — `save.seen`.
- `js/story.js` — сюжет (`STORY`): герой Бит, персонажи, пролог, у каждого урока проводник, место квеста (`place`, пишется над заданием), вступление и прощание. Вступление показывается при первом входе в урок, прощание — когда пройдены все задания урока.
- `js/gear.js` — прокачка (`HeroGear`): уровни по звёздам всего курса, снаряжение по слотам (`head`, `neck`, `back`, `pet`, `color`) и его 3D-модели из примитивов (герой смотрит в +z, голова на высоте 0.62). Новая вещь сразу надевается при получении уровня.

## Правила для новых заданий
- В уроках с условиями карта должна меняться от сида так, чтобы решение «под одну карту» ломалось, а решение с условием работало всегда. В уроках без условий (`basic`) карта одна, нарисованная.
- Стартовый код ломается, `hints[2]` — эталонное решение, `best` — число строк для третьей звезды (или `star3: 'first'` — звезда за решение с первого запуска, если «коротко» даётся даром).
- Типичные неверные решения задания и другие верные варианты перечислены в `tests/check-tasks.js` — дополняй их вместе с заданием.
- Урок строится по образцу Swift Playgrounds: подсказок всё меньше (с 4-го задания над редактором все команды урока — в уроках с условиями это `ALL_CMDS`, стартовый код не подсказывает ответ, финал пишется с нуля). По содержанию сверяемся со школьной программой (Робот в КуМире, ОГЭ): сравнения, `and`/`or`/`not`, `while`.
- Особые карты: `need` — сколько монет нести (больше не взять, ошибка `full`), `stop: true` — победа, только если программа закончилась на флаге (ошибка `stop`), `answer` — что Бит должен сказать командой `сказать()` на флаге (число или `'steps'` — сколько раз шагнул вперёд; ошибка `answer`), `hidden` — флаг не виден и `на_финише()` не работает, `gates` — ворота (`ворота_впереди()`, `открыть()`), `signs` — таблички с числами (`табличка()` только стоя на ней), `english` — работают только английские имена команд (`EN` в world.js), `broken` — «сломанные» команды, `boss` — Великий Сбой на месте флага. На трёх картах ответ `answer` должен быть разным — иначе угадывается числом.
- Генераторы для карт: `corridor` (отрезки с поворотами), `winding` (случайный путь без касаний), `corners`, `pickLava`, `maze` (лабиринт без петель) и `handWalk` (путь по правилу руки — чтобы класть монеты туда, куда Бит точно зайдёт). У задания `fast` — ускорение анимации (в лабиринтах `fast: 3`).
- Вечный цикл ловится сам: если Бит больше 25 раз оказывается в одном и том же положении (не на флаге), программа останавливается с ошибкой `loop`.
- Новую команду героя добавить в `commands()` (world.js), в `HERO_CMDS` (app.js) для подсветки и, если нужно, анимацию в `animate()`.
- Новый урок — вместе с сюжетом в `js/story.js` (проводник, место, вступление, прощание) и, если нужно, новыми уровнями в `js/gear.js`: последний уровень должен быть достижим звёздами курса.
- Тексты для детей: коротко, на «ты», без канцелярита.

## Проверка
`node tests/check-tasks.js` — для каждого задания всех уроков решение проходит все карты (на 40 сидах), стартовый код ломается, типичные ошибки ломаются с нужной причиной, эталон укладывается в `best`; уроки подключены в `index.html`, `id` не повторяются. Запускать после любых изменений в уроках, minipy.js или world.js. Глубже: `SEEDS=1000 node tests/check-tasks.js`.
`node tests/check-story.js` — у каждого урока есть сюжет, реплики ссылаются на существующих персонажей и не длиннее 160 знаков; уровни идут по возрастанию и достижимы; каждая вещь собирается в three.js.
