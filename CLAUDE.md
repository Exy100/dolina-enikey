# Долина Эникей — заметки для Claude

Учебный 3D-тренажёр по Python для начинающих с 12 лет. Интерфейс и все тексты — на русском.
Это инструмент репетитора: занятия 1 на 1 онлайн, ученик показывает экран. Концепция, сценарий часа, работа с клиентами (Авито) и план — в `PLAN.md`, сверяйся с ним.
Ученик пишет код в редакторе, герой выполняет его в 3D-мире. Курс — пролог (пробное занятие, 4 задания) и 7 уроков: «Команды» (4 задания — первая домашка), «Циклы» (у заданий пролога и этих двух уроков одна нарисованная карта), «Условия», «Цикл while», «Переменные», «Функции», «Лабиринт» (по 8 заданий, каждое решение проверяется на трёх случайных картах). В уроках 1–7 есть задание со звёздочкой, в уроках 2–7 — разминка из прошлых уроков.

## Устройство
- Сборки нет: чистые HTML/CSS/JS, скрипты подключаются тегами `<script>` в `index.html`, без модулей и npm-зависимостей.
- `js/three.min.js` — three.js r128 (UMD, глобальный `THREE`). Не обновлять без необходимости: в r128 нет CapsuleGeometry.
- `js/minipy.js` — свой интерпретатор подмножества Python (генераторы, пошаговое выполнение). Ошибки — `PyError` с понятным русским текстом и номером строки. Имена нормализуются: `ё` → `е` (`вперёд` и `вперед` — одно и то же). Есть `def` с параметрами и `return`: внутри приёма свои переменные, внешние можно читать, но не менять (понятная ошибка). Свой приём с именем команды заменяет её — так в лабиринте чинят «сломанный» `turn_right()`. Событие `line` несёт `scope()` — снимок переменных для панели «Переменные» (функция, чтобы тихий прогон не тратил время).
- `js/world.js` — движок мира: команды героя, карты (`fromAscii`, `corridor`, `pickLava`), `LESSONS` и `addLesson`. Команды героя — генераторы, которые меняют состояние и `yield`-ят события для анимации (`move`, `turn`, `jump`, `take`, `check`, `bump`, `burn`, `win` …). Провал — `WorldError` с полем `kind`, победа — `WinSignal`. Свой уровень: `checkLevel(rows)` проверяет карту из редактора (один старт, один флаг, всё достижимо; монета за флагом — отдельная причина) и строит решение `planRoute` (кратчайший путь с прыжками, монеты в лучшем порядке, шаги сжаты в `вперёд(n)`).
- `js/lessons/N-id.js` — по файлу на урок, вызывают `HeroWorld.addLesson({ id, title, intro, basic, tasks })`. Порядок уроков — порядок `<script>` в `index.html`; тест проверяет, что каждый файл подключён. `basic: true` — урок без условий: у задания `map` (карта-рисунок, одна), в сообщениях об ошибках нет советов про `if`/датчики, а флаг засчитывается только в конце программы — шаг или прыжок с флага даёт ошибку `extra` («лишние команды»). Поэтому если последний повтор цикла кончается `взять()`, на флаге тоже лежит монета (`@` на карте). Уроки с условиями используют `gen` (три случайные карты). `prologue: true` — пролог (`0-prolog.js`): идёт первым и без номера («Урок 1» — следующий), только одиночные шаги без чисел в скобках; когда пройдены все его задания, «Дальше» показывает сцену со Сбоем и карточку «Итог пролога». `bonus: [задание]` — задание со звёздочкой (необязательное, звёзды идут в уровень Бита, для прощания урока не нужно). `warmup: ['id', …]` — разминка: id заданий прошлых уроков; в app.js это копии с id `w:…`, свежими картами, стартом с нуля и без звёзд. `topic: { name, code }` — тема урока для страницы героя (как называется и как выглядит в коде).
- `js/app.js` — three.js-сцена, анимация событий, редактор с подсветкой, выбор урока, звёзды, подсказки, прогресс в localStorage (ключ `mir-geroya-usloviya-v1`, не менять, иначе ученики потеряют прогресс). Прогресс ключуется по `id` задания, поэтому `id` уникальны во всём курсе и не переименовываются; текущий урок и задание — `save.lesson` и `save.pos`; надетые вещи — `save.gear`, показанные реплики — `save.seen`, счёт догадок — `save.predict`. След героя (`trailGroup`: точки, стрелки, дуги прыжков, красное кольцо сбоя) рисуется из событий `move`/`jump` и живёт отдельно от `levelGroup`. Пролог вынесен из урока «Команды»: старое `save.pos.komandy` переносится по `id` задания (признак, что перенос уже был, — есть `save.pos.prolog`). Сцена конца пролога — `cutscene(lines, done)`: эффекты реплик `CUT_FX` (`key` — Ключ-код над флагом, `sboy` — темнеет небо, `.world.storm`/`.glitch`, появляется Сбой из `makeSboy()`, `steal` — Сбой уносит ключ); «Пропустить» возвращает мир как был (`endCutscene`). Карточка «Итог пролога» (`#recap`, `openRecap`) — для родителя: статистика, 3D-портрет Бита (отдельный маленький `WebGLRenderer` с клоном героя, закрывается вместе с карточкой), последняя программа с подсветкой, путь по долине; повторно открывается кнопкой в панели героя. Вкладки урока (`lessonTasks`): основные задания (их номер хранится в `save.pos`), задание со звёздочкой (`kind: 'bonus'`), разминка (`kind: 'warm'`, отметки — `save.warm`) и свой уровень (`kind: 'custom'`); на вкладках порядок: разминка, задания, ★, ✎. В новом уроке первой открывается разминка. Подсказка к строке (`lineHint`): `runOnMap` пишет в `st.trace`, на какой строке (`line`, `stamp` — номер запуска строки) Бит попал на каждую клетку; по ошибке `kind` и положению Бита совет говорит, куда уходит дорога относительно его взгляда, сколько шагов было нужно, где он прошёл по монете или встал на флаг. Панель «Переменные» (`#vars`, `showVars`) обновляется на событии `line`. Карта долины (`#valley`, `renderValley`, `VALLEY` — места и значки по порядку уроков) заменяет список уроков (`#lessonSel` скрыт, но остаётся): пройденные края с галочкой, «Бит здесь», дальние края в тумане, но кликабельны. Свой уровень: редактор `#lvlEd` (`openEditor`), карта в `save.custom` (`title`, `rows`, `w`, `h`), ссылка `#level=` — base64url от JSON `{ t, r }`, при открытии проверяется `checkLevel`; звёзды за свой уровень не сохраняются. Домашка: ссылка `#hw=id,id…` (или `#task=id`) — `hwFromLink` чистит адрес, отбрасывает неизвестные id и пишет `save.hw` (`ids`, `at`); при старте и на `hashchange` открывается первое нерешённое задание (`goTask` — переход к заданию любого урока по id через `findTask`, без автозапуска разминки). Над заданием полоска `#hw` (`renderHw`: пункты с галочками, «×» удаляет `save.hw`), вкладки из домашки с кольцом (`hwmark`), после решения «Дальше» ведёт к следующему нерешённому заданию домашки (`hwNextId`). Окно «Задать домашку» (`#hwEd`, кнопка `#valleyHw` на карте долины): галочки по урокам, быстрые кнопки 1–4 / 5–8 / все, по умолчанию задания 5–8 текущего урока (из пролога — урок «Команды»), готовое сообщение со ссылкой (`hwOutput`, номера сжаты в диапазоны `hwRanges`). Страница героя (`#heroPage`, `openHeroPage`; открывается кнопкой с уровнем Бита в шапке): 3D-остров края, где сейчас Бит (`buildIsland` по значку из `VALLEY`, свой `WebGLRenderer` в `startIsland`/`stopIsland`, Бит — `makeHeroModel(gear)`: копия героя со своим снаряжением и цветами; остров крутится мышью или пальцем), звание и полоска уровня, статистика, темы курса (`topic` уроков), достижения, снаряжение (бывшая панель) и последняя программа. Всё рисуется по сводке `D = heroData()`: `s` — звёзды по урокам строкой цифр 0–7 (биты трёх звёзд, основные задания, потом звёздочка), `g` — снаряжение, `t` — титул (`save.badge`), `n` — имя (`save.name`), `r` — край, `f` — решено с первого запуска (`save.first` или нет `save.fails`), `w` — разминки, `h` — сделанные домашки (`save.hwDone`, `save.hw.done`), `u` — свой уровень нарисован (`save.built`), `d` — дни занятий (`save.days`, `markDay` при запуске), `k` — строки кода, `p` — догадки `[верно, всего, лучшая серия]` (`save.predict.streak`/`best`), `c` — последняя программа (`save.lastWin`). `heroSummary(D)` считает прогресс по урокам и счётчики `A` для достижений (`js/awards.js`). `checkAwards()` после решения, разминки, «Угадай» и редактора: новое достижение — строка в журнале и в карточке результата, звук `award`, точка на кнопке героя (`save.awardsNew`); полученные — `save.awards` (при первом запуске запоминаются молча). Ссылка «Поделиться» `#hero=` — base64url от JSON `D`, проверяется `cleanHero`; по ней страница открывается поверх заставки только для просмотра (`hpShared`, кнопка «Открыть Долину»), прогресс гостя не трогается. Режим «Угадай» (`guessGroup`, кнопка `#guessBtn`): `simulate` молча прогоняет программу и находит, где встанет Бит; `guessOptions` добавляет два правдоподобных неверных варианта (флаг, шаг дальше, шаг раньше, старт). Варианты А/Б/В — значки-спрайты над клетками и кнопки в `#guessOpts`; выбрать можно значком, кнопкой или клавишей 1/2/3. Потом программа запускается на текущей карте без звёзд, верный вариант зеленеет (`runOnMap` возвращает `st`). Правка кода сбрасывает варианты.
- `js/story.js` — сюжет (`STORY`): герой Бит, персонажи, пролог, у каждого урока проводник, место квеста (`place`, пишется над заданием), вступление и прощание. Реплика — `[кто, текст]` или `[кто, текст, эффект]`: эффекты описаны в `STORY.fx` и рисуются в app.js (`CUT_FX`). Арка главы 1: Сбой — первая программа Ады с ошибкой; в прощании пролога он крадёт Ключ-код и намекает на прошлое, Кузнец (урок 6) проговаривается, у ворот замка (урок 7) Ада признаётся, в финале Сбоя чинят (персонаж `fixed`, в 3D босс светлеет и успокаивается — `userData.fixed`), и Ключ-код возвращается. Бит понимает всё буквально: при ошибках `extra`, `short`, `coins`, `loop` он говорит об этом в облачке (`BIT_SAYS` в app.js). Вступление показывается при первом входе в урок, прощание — когда пройдены все задания урока.
- `js/sound.js` — звуки (`Sound`): всё синтезируется Web Audio, без файлов. `Sound.play('coin', { n })`, список звуков — `SFX`; включаются после первого нажатия (`Sound.unlock()`), кнопка звука в углу мира (`#soundBtn`, `save.mute`). Новый звук — в `SFX`; тест проверяет, что каждый `Sound.play('…')` из app.js там есть.
- Режим показа для видео на Авито — `index.html?show` (app.js, `REEL`, `startReel`): титульная карточка, затем Бит сам проходит 5 уровней (код печатается буква за буквой, на уровне с `again` — ещё и вторая карта), финальная карточка с призывом. Прогресс ученика не читается и не пишется (`SHOW`, `persist` ничего не делает), Бит — в шляпе, шарфе и с рюкзаком. Карты фиксированы (`REEL.seed`), у уровня своя скорость (`speed`), ролик идёт около 70 с. Окно выше, чем шире, — вертикальное видео: мир сверху, код снизу. Уровни ролика проверяет `tests/check-tasks.js`.
- `js/awards.js` — достижения (`HeroAwards`): `LIST` (`id`, `name`, `desc`, `key` — счётчик из сводки `A`, `goal`, `hue` — цвет медали, `icon` — линии в квадрате 24 × 24) и `evaluate(A)`. Новое достижение — счётчик добавить в `heroSummary` (app.js) и в проверку достижимости в `tests/check-story.js`.
- `js/gear.js` — прокачка (`HeroGear`): уровни по звёздам всего курса, снаряжение по слотам (`head`, `neck`, `back`, `pet`, `color`) и его 3D-модели из примитивов (герой смотрит в +z, голова на высоте 0.62). Новая вещь сразу надевается при получении уровня.

## Правила для новых заданий
- В уроках с условиями карта должна меняться от сида так, чтобы решение «под одну карту» ломалось, а решение с условием работало всегда. В уроках без условий (`basic`) карта одна, нарисованная.
- Стартовый код ломается, `hints[2]` — эталонное решение, `best` — число строк для третьей звезды (или `star3: 'first'` — звезда за решение с первого запуска, если «коротко» даётся даром).
- Типичные неверные решения задания и другие верные варианты перечислены в `tests/check-tasks.js` — дополняй их вместе с заданием. Это касается и заданий со звёздочкой (`bonus`); в разминку (`warmup`) — только задания прошлых уроков.
- Урок строится по образцу Swift Playgrounds: подсказок всё меньше (с 4-го задания над редактором все команды урока — в уроках с условиями это `ALL_CMDS`, стартовый код не подсказывает ответ, финал пишется с нуля). По содержанию сверяемся со школьной программой (Робот в КуМире, ОГЭ): сравнения, `and`/`or`/`not`, `while`.
- Особые карты: `need` — сколько монет нести (больше не взять, ошибка `full`), `stop: true` — победа, только если программа закончилась на флаге (ошибка `stop`), `answer` — что Бит должен сказать командой `сказать()` на флаге (число или `'steps'` — сколько раз шагнул вперёд; ошибка `answer`), `hidden` — флаг не виден и `на_финише()` не работает, `gates` — ворота (`ворота_впереди()`, `открыть()`), `signs` — таблички с числами (`табличка()` только стоя на ней), `english` — работают только английские имена команд (`EN` в world.js), `broken` — «сломанные» команды, `boss` — Великий Сбой на месте флага. На трёх картах ответ `answer` должен быть разным — иначе угадывается числом.
- Генераторы для карт: `corridor` (отрезки с поворотами), `winding` (случайный путь без касаний), `corners`, `pickLava`, `maze` (лабиринт без петель) и `handWalk` (путь по правилу руки — чтобы класть монеты туда, куда Бит точно зайдёт). У задания `fast` — ускорение анимации (в лабиринтах `fast: 3`).
- Вечный цикл ловится сам: если Бит больше 25 раз оказывается в одном и том же положении (не на флаге), программа останавливается с ошибкой `loop`.
- Новую команду героя добавить в `commands()` (world.js), в `HERO_CMDS` (app.js) для подсветки и, если нужно, анимацию в `animate()`.
- Новый урок — вместе с сюжетом в `js/story.js` (проводник, место, вступление, прощание) и, если нужно, новыми уровнями в `js/gear.js`: последний уровень должен быть достижим звёздами курса.
- Тексты для детей: коротко, на «ты», без канцелярита. Учатся и мальчики, и девочки: к ученику без мужского рода (не «ты прошёл», не «пиши сам» — «весь курс пройден», «пиши с нуля»); это проверяет `tests/check-story.js`.

## Проверка
`node tests/check-tasks.js` — для каждого задания всех уроков решение проходит все карты (на 40 сидах), стартовый код ломается, типичные ошибки ломаются с нужной причиной, эталон укладывается в `best`; уроки и `sound.js` подключены в `index.html`, `id` не повторяются, уровни ролика `REEL` есть в курсе и проходят свои карты; задания со звёздочкой проверяются как обычные, разминка ссылается на прошлые уроки, `checkLevel` принимает годные карты своих уровней (и их решение проходит) и отклоняет битые. Запускать после любых изменений в уроках, minipy.js или world.js. Глубже: `SEEDS=1000 node tests/check-tasks.js`.
`node tests/check-story.js` — у каждого урока есть сюжет, реплики ссылаются на существующих персонажей и не длиннее 160 знаков, эффекты реплик есть в `STORY.fx`, пролог один и первый, а в его прощании эффекты `key`, `sboy`, `steal` по порядку; в репликах, текстах заданий и сообщениях нет мужского рода в обращении к ученику; каждый звук из app.js есть в sound.js; уровни идут по возрастанию и достижимы; каждая вещь собирается в three.js; у каждого урока есть `topic`; у достижений уникальные id, счётчик есть в сводке app.js, цель достижима, `awards.js` подключён.
