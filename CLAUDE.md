# Долина Эникей — заметки для Claude

Учебный 3D-тренажёр по Python для начинающих с 12 лет. Интерфейс и все тексты — на русском.
Это инструмент репетитора: занятия 1 на 1 онлайн, ученик показывает экран. Концепция, сценарий часа, работа с клиентами (Авито) и план — в `PLAN.md`, сверяйся с ним.
Ученик пишет код в редакторе, герой выполняет его в 3D-мире. Курс — пролог (пробное занятие, 4 задания) и 7 уроков: «Команды» (4 задания — первая домашка), «Циклы» (у заданий пролога и этих двух уроков одна нарисованная карта), «Условия», «Цикл while», «Переменные», «Функции», «Лабиринт» (по 8 заданий, в «Цикле while», «Переменных», «Функциях» и «Лабиринте» — по 9, с «Катком», «Кодовым замком», «Рычагами» и «Дозорными», каждое решение проверяется на трёх случайных картах). В уроках 1–7 есть задание со звёздочкой, в уроках 2–7 — разминка из прошлых уроков. Итог главы — Испытание Сбоя: 6 заданий по темам на новых картах, результат — карточкой для родителя, повтор через месяц-два показывает рост. Для родителей и Авито — грамота (печать A4 и картинка), кадры для объявления (`?shots`) и сообщения родителям.

## Устройство
- Сборки нет: чистые HTML/CSS/JS, скрипты подключаются тегами `<script>` в `index.html`, без модулей и npm-зависимостей.
- `js/three.min.js` — three.js r128 (UMD, глобальный `THREE`). Не обновлять без необходимости: в r128 нет CapsuleGeometry.
- `js/minipy.js` — свой интерпретатор подмножества Python (генераторы, пошаговое выполнение). Ошибки — `PyError` с понятным русским текстом и номером строки. Имена нормализуются: `ё` → `е` (`вперёд` и `вперед` — одно и то же). Есть `def` с параметрами и `return`: внутри приёма свои переменные, внешние можно читать, но не менять (понятная ошибка). Свой приём с именем команды заменяет её — так в лабиринте чинят «сломанный» `turn_right()`. Событие `line` несёт `scope()` — снимок переменных для панели «Переменные» (функция, чтобы тихий прогон не тратил время). У `print` есть `sep=` и `end=` (событие `print` несёт `end`); `stdlib({ console: true })` добавляет `input()`: событие `input` с `prompt`, ответ возвращают через `next(ответ)`. f-строки и методы через точку не поддерживаются — на них понятная ошибка.
- `js/world.js` — движок мира: команды героя, карты (`fromAscii`, `corridor`, `pickLava`), `LESSONS` и `addLesson`. Команды героя — генераторы, которые меняют состояние и `yield`-ят события для анимации (`move`, `turn`, `jump`, `take`, `check`, `bump`, `burn`, `win` …). Провал — `WorldError` с полем `kind`, победа — `WinSignal`. Свой уровень: `checkLevel(rows)` проверяет карту из редактора (один старт, один флаг, всё достижимо; монета за флагом — отдельная причина) и строит решение `planRoute` (кратчайший путь с прыжками, монеты в лучшем порядке, шаги сжаты в `вперёд(n)`).
- `js/lessons/N-id.js` — по файлу на урок, вызывают `HeroWorld.addLesson({ id, title, intro, basic, tasks })`. Порядок уроков — порядок `<script>` в `index.html`; тест проверяет, что каждый файл подключён. `basic: true` — урок без условий: у задания `map` (карта-рисунок, одна), в сообщениях об ошибках нет советов про `if`/датчики, а флаг засчитывается только в конце программы — шаг или прыжок с флага даёт ошибку `extra` («лишние команды»). Поэтому если последний повтор цикла кончается `взять()`, на флаге тоже лежит монета (`@` на карте). Уроки с условиями используют `gen` (три случайные карты). `prologue: true` — пролог (`0-prolog.js`): идёт первым и без номера («Урок 1» — следующий), только одиночные шаги без чисел в скобках; когда пройдены все его задания, «Дальше» показывает сцену со Сбоем и карточку «Итог пролога». `bonus: [задание]` — задание со звёздочкой (необязательное, звёзды идут в уровень Бита, для прощания урока не нужно). `warmup: ['id', …]` — разминка: id заданий прошлых уроков; в app.js это копии с id `w:…`, свежими картами, стартом с нуля и без звёзд. `topic: { name, code }` — тема урока для страницы героя (как называется и как выглядит в коде).
- `js/app.js` — three.js-сцена, анимация событий, редактор с подсветкой, выбор урока, звёзды, подсказки, прогресс в localStorage (ключ `mir-geroya-usloviya-v1`, не менять, иначе ученики потеряют прогресс). Прогресс ключуется по `id` задания, поэтому `id` уникальны во всём курсе и не переименовываются; текущий урок и задание — `save.lesson` и `save.pos`; надетые вещи — `save.gear`, показанные реплики — `save.seen`, счёт догадок — `save.predict`. След героя (`trailGroup`: точки, стрелки, дуги прыжков, красное кольцо сбоя) рисуется из событий `move`/`jump` и живёт отдельно от `levelGroup`. Пролог вынесен из урока «Команды»: старое `save.pos.komandy` переносится по `id` задания (признак, что перенос уже был, — есть `save.pos.prolog`). Сцена конца пролога — `cutscene(lines, done)`: эффекты реплик `CUT_FX` (`key` — Ключ-код над флагом, `sboy` — темнеет небо, `.world.storm`/`.glitch`, появляется Сбой из `makeSboy()`, `steal` — Сбой уносит ключ); «Пропустить» возвращает мир как был (`endCutscene`). Карточка «Итог пролога» (`#recap`, `openRecap`) — для родителя: статистика, 3D-портрет Бита (отдельный маленький `WebGLRenderer` с клоном героя, закрывается вместе с карточкой), последняя программа с подсветкой, путь по долине; повторно открывается кнопкой в панели героя. Вкладки урока (`lessonTasks`): основные задания (их номер хранится в `save.pos`), задание со звёздочкой (`kind: 'bonus'`), разминка (`kind: 'warm'`, отметки — `save.warm`) и свой уровень (`kind: 'custom'`); на вкладках порядок: разминка, задания, ★, ✎. В новом уроке первой открывается разминка. Подсказка к строке (`lineHint`): `runOnMap` пишет в `st.trace`, на какой строке (`line`, `stamp` — номер запуска строки) Бит попал на каждую клетку; по ошибке `kind` и положению Бита совет говорит, куда уходит дорога относительно его взгляда, сколько шагов было нужно, где он прошёл по монете или встал на флаг. Панель «Переменные» (`#vars`, `showVars`) обновляется на событии `line`. Карта долины (`#valley`, `renderValley`, `VALLEY` — места и значки по порядку уроков) заменяет список уроков (`#lessonSel` скрыт, но остаётся): пройденные края с галочкой, «Бит здесь», дальние края в тумане, но кликабельны. Свой уровень: редактор `#lvlEd` (`openEditor`), карта в `save.custom` (`title`, `rows`, `w`, `h`), ссылка `#level=` — base64url от JSON `{ t, r }`, при открытии проверяется `checkLevel`; звёзды за свой уровень не сохраняются. Домашка: ссылка `#hw=id,id…` (или `#task=id`) — `hwFromLink` чистит адрес, отбрасывает неизвестные id и пишет `save.hw` (`ids`, `at`); при старте и на `hashchange` открывается первое нерешённое задание (`goTask` — переход к заданию любого урока по id через `findTask`, без автозапуска разминки). Над заданием полоска `#hw` (`renderHw`: пункты с галочками, «×» удаляет `save.hw`), вкладки из домашки с кольцом (`hwmark`), после решения «Дальше» ведёт к следующему нерешённому заданию домашки (`hwNextId`). Окно «Задать домашку» (`#hwEd`, кнопка `#valleyHw` на карте долины): галочки по урокам, быстрые кнопки 1–4 / 5–8 / все, по умолчанию задания 5–8 текущего урока (из пролога — урок «Команды»), готовое сообщение со ссылкой (`hwOutput`, номера сжаты в диапазоны `hwRanges`). Страница героя (`#heroPage`, `openHeroPage`; открывается кнопкой с уровнем Бита в шапке): 3D-остров края, где сейчас Бит (`buildIsland` по значку из `VALLEY`, свой `WebGLRenderer` в `startIsland`/`stopIsland`, Бит — `makeHeroModel(gear)`: копия героя со своим снаряжением и цветами; остров крутится мышью или пальцем, `island.turn` поворачивает его спиной для вещей на спину), справа звание и вкладки (`showTab`): «Прогресс» (полоска уровня, статистика), «Лавка Ады», «Снаряжение» (бывшая панель); ниже темы курса (`topic` уроков), достижения и последняя программа. Кристаллы: заработано (`HeroAwards.gemsEarned` по сводке `A`) минус потрачено в лавке — `heroSummary(D).gems` (`earned`, `spent`, `left`); счётчик на острове `#hpGems`. Лавка Ады (`renderShop`): вещи `HeroGear.SHOP`, нажатие — примерка на острове (`tryOn`, рамка `#hpTry` с «Купить»), покупка — `save.shop`, купленное сразу надевается; куплено — значит открыто (`isOpen`), такие вещи есть и в «Снаряжении». Кристаллы за верную догадку — один раз за задание (`save.guessed`, свои уровни не считаются). Всё рисуется по сводке `D = heroData()`: `s` — звёзды по урокам строкой цифр 0–7 (биты трёх звёзд, основные задания, потом звёздочка), `g` — снаряжение, `t` — титул (`save.badge`), `n` — имя (`save.name`), `r` — край, `f` — решено с первого запуска (`save.first` или нет `save.fails`), `w` — разминки, `h` — сделанные домашки (`save.hwDone`, `save.hw.done`), `u` — свой уровень нарисован (`save.built`), `d` — дни занятий (`save.days`, `markDay` при запуске), `k` — строки кода, `p` — догадки `[верно, всего, лучшая серия]` (`save.predict.streak`/`best`), `q` — задания с верной догадкой, `y` — решено в консоли Python, `b` — купленное в лавке, `c` — последняя программа (`save.lastWin`). `heroSummary(D)` считает прогресс по урокам и счётчики `A` для достижений (`js/awards.js`). `checkAwards()` после решения, разминки, «Угадай» и редактора: новое достижение и прибавка кристаллов — строка в журнале и в карточке результата, звук `award`, точка на кнопке героя (`save.awardsNew`); полученные — `save.awards`, сколько кристаллов уже показано — `save.gemsSeen` (при первом запуске всё запоминается молча). Ссылка «Поделиться» `#hero=` — base64url от JSON `D`, проверяется `cleanHero`; по ней страница открывается поверх заставки только для просмотра (`hpShared`, кнопка «Открыть Долину»), прогресс гостя не трогается. Консоль Python (задания `kind: 'py'` из `js/bridge.js`, вкладки «›_ 1…» после ★): вместо мира — `#pyw` (карточка «у Бита → в обычном Python», свёрнутый план для репетитора `#tutor` и консоль `#pycOut`), над редактором — пример ввода и вывода `#pySample`, файл называется `main.py`, «Угадай» скрыт. `runPy`: сначала живой прогон `runConsole` (печать в консоль, ответ на `input()` — поле `.pyc-in` прямо в консоли, первые 150 строк с подсветкой), потом тихая проверка `HeroBridge.check`; не прошло — `pyFail` говорит, на каком вводе и какая строка вывода не та. «Шаг» (`stepPy`) работает и здесь. Решённое — `save.py` (без звёзд, галочка на вкладке), «Дальше» — следующее задание в консоли (`finishPy`, общий хвост с заданиями Бита — `afterSolve`: домашка и достижения). Задания консоли можно задавать на дом (кнопка «Python» в окне «Задать домашку»), за пять решённых — достижение «Настоящий Python». Крупный шрифт для демонстрации экрана — кнопка `#bigBtn` «A+» над кодом (`save.big`, класс `body.big`). Режим «Угадай» (`guessGroup`, кнопка `#guessBtn`): `simulate` молча прогоняет программу и находит, где встанет Бит; `guessOptions` добавляет два правдоподобных неверных варианта (флаг, шаг дальше, шаг раньше, старт). Варианты А/Б/В — значки-спрайты над клетками и кнопки в `#guessOpts`; выбрать можно значком, кнопкой или клавишей 1/2/3. Потом программа запускается на текущей карте без звёзд, верный вариант зеленеет (`runOnMap` возвращает `st`). Правка кода сбрасывает варианты.
- `js/story.js` — сюжет (`STORY`): герой Бит, персонажи, пролог, у каждого урока проводник, место квеста (`place`, пишется над заданием), вступление и прощание. Реплика — `[кто, текст]` или `[кто, текст, эффект]`: эффекты описаны в `STORY.fx` и рисуются в app.js (`CUT_FX`). Реплики Испытания Сбоя — `STORY.trial` (`intro`, после финала — `fixed`: починенный Сбой сам проверяет). Арка главы 1: Сбой — первая программа Ады с ошибкой; в прощании пролога он крадёт Ключ-код и намекает на прошлое, Кузнец (урок 6) проговаривается, у ворот замка (урок 7) Ада признаётся, в финале Сбоя чинят (персонаж `fixed`, в 3D босс светлеет и успокаивается — `userData.fixed`), и Ключ-код возвращается. Бит понимает всё буквально: при ошибках `extra`, `short`, `coins`, `loop` он говорит об этом в облачке (`BIT_SAYS` в app.js). Вступление показывается при первом входе в урок, прощание — когда пройдены все задания урока.
- `js/sound.js` — звуки (`Sound`): всё синтезируется Web Audio, без файлов. `Sound.play('coin', { n })`, список звуков — `SFX`; включаются после первого нажатия (`Sound.unlock()`), кнопка звука в углу мира (`#soundBtn`, `save.mute`). Новый звук — в `SFX`; тест проверяет, что каждый `Sound.play('…')` из app.js там есть.
- Кадры для объявления — `index.html?shots` (app.js, раздел «Кадры для Авито», `startShots`): тоже показ (`SHOW` — прогресс ученика не читается и не пишется, Бит в шляпе, шарфе и с рюкзаком), но вместо ролика — галерея `#shots` из восьми постеров (`js/poster.js`). `buildShots` готовит картинки: `shotWorld` выбирает задание, строит карту по `HeroPoster.SEED`, прогоняет эталон (виден след; `near: 'boss'` — остановиться рядом со Сбоем, пока его не починили) и снимает мир `grabWorld(w, h, focus)` сразу под оба формата кадра (`HeroPoster.slot`); `islandImage` — остров края с Битом, `heroPortrait` — портрет для грамоты и призыва, `shotCert` — грамота за главу на имя «Саша». Код на кадрах — `codeTokens` (та же подсветка `highlight`). Формат 4:3 (1600 × 1200) или 1:1 (1200 × 1200), «Скачать» — PNG `avito-N-id-4x3.png`, «Скачать все» — по очереди. Шрифты игры загрузились позже — кадры перерисовываются.
- Режим показа для видео на Авито — `index.html?show` (app.js, `REEL`, `startReel`): титульная карточка, затем Бит сам проходит 5 уровней (код печатается буква за буквой, на уровне с `again` — ещё и вторая карта), финальная карточка с призывом. Прогресс ученика не читается и не пишется (`SHOW`, `persist` ничего не делает), Бит — в шляпе, шарфе и с рюкзаком. Карты фиксированы (`REEL.seed`), у уровня своя скорость (`speed`), ролик идёт около 70 с. Окно выше, чем шире, — вертикальное видео: мир сверху, код снизу. Уровни ролика проверяет `tests/check-tasks.js`.
- `js/bridge.js` — мост к Python (`HeroBridge`): для каждого урока `LESSONS[id]` — `text`, код Бита `bit` и тот же смысл на обычном Python `py` (`pyIn` — ответы на `input` примера), план живого кодирования для репетитора `tutor` и задания в консоли `tasks` (id `py-…`, `kind: 'py'`; `tests` — наборы ответов на `input` (`in`) и, для самопроверки и примера, `out`; `use` — что обязательно в коде, если ответ иначе можно просто напечатать). Правильный вывод даёт эталон `hints[2]`; `run(code, inputs)` — тихий прогон (вывод только `print`, подсказки `input` не входят), `check(task, code)` — проверка на всех `tests`, вывод сравнивается построчно без учёта пробелов в конце, регистра и ё. Имена переменных в решениях — английские, как в обычном Python; деление `/` не используем (в Python 10 / 2 = 5.0).
- `js/trial.js` — Испытание Сбоя (`HeroTrial`): `TASKS` — шесть заданий `kind: 'exam'` (id `ex-…`), по одному на тему главы: `topic` — урок темы (`lessons` — если уроков несколько), `name` — тема для карточки, `short` — вкладка, `maps` — 1 (карта-рисунок по сиду, `basic`, эталон строит `solve(L)`, например `planRoute`) или 3 (одна программа на три карты, эталон — `hints[2]`), `need` — обязательная конструкция темы (`for`, `while`, `def`): без неё Бит доходит, но испытание не засчитано (`unmet(task, code)`). У «Считалки» (`stop`, `answer` — сколько поворотов) ответ на трёх картах разный (`fresh`). Ещё `reference(task, L)`, маски тем `toMask`/`fromMask`/`count`. Звёзд за испытание нет (`best: 99`). Подключается после уроков.
- Режим испытания (app.js, раздел «Испытание Сбоя»): окно старта `#trialCard` (`openTrialCard`: темы — пройдена, впереди или решено; прошлые попытки столбиками; если прошлое испытание было меньше 14 дней назад — предупреждение и «Всё равно начать»; до конца пролога закрыто), кнопка `#valleyTrial` на карте долины и раздел `#hpTrialSec` на странице героя. `startTrial` берёт новый сид (`save.seeds[id]`), очищает код и подсказки этих заданий и говорит реплику Сбоя (`STORY.trial.intro`, после финала курса — `fixed`). Во время попытки (`inTrial`, `enterTrial`/`leaveTrial`) вкладки — шесть испытаний с ✓, над заданием полоска `#trialBar` (`renderTrialBar`: «Решено k из 6», «Завершить» переспрашивает, «Выйти» — попытка ждёт), метка «Тема:» вместо «Новое:»; нет подсказок, «Угадай», новых карт, подсказки к строке и полоски домашки. Решение засчитывается `finishExam` с номером запуска (`runAll` считает `cur.runs`). Попытка — `save.trial.cur` (`at`, `seed`, `ok` — id → номер запуска решения, `runs`, `ahead` — маска тем, до которых уроки не дошли, `active` — открыта: после перезагрузки продолжается сама; `spent`/`last` — активное время: `trialTick` на входе, запуске, «Шаге», правке и решении прибавляет промежуток не больше 10 минут, перерывы не считаются). `endTrial` пишет в `save.trial.hist` запись `{ at, end, s, ahead, t }` (`s` — номер запуска решения по заданиям, 0 — не решено; `t` — активное время; хранится 30, первая — точка отсчёта — не удаляется). Итог `#trialRes` (`openTrialResult`): кольцо по заданиям, статус тем («с первого запуска», «с N-го запуска», «тема ещё впереди», «пока не получилось»), сводка «Получается / Стоит повторить / Ещё впереди / Время», столбики попыток и «Было X из 6 (дата), стало Y из 6: на K больше за …». «Поделиться» (`trialOutput`) — ссылка `#trial=` (base64url от JSON `{ v: 1, n, h: [[at, end в минутах, s, ahead, t в минутах]] }`, проверяется `cleanTrial`) и готовое сообщение; по ссылке итог открывается поверх заставки только для просмотра. Столбики и ссылки берут не больше 8 попыток (`keyAttempts`: первая, лучшая и последние). В сводке героя `x` — попытки `[конец в минутах, решено]`, `A.trial` — лучший счёт (достижение «Испытание Сбоя» за 6 из 6).
- `js/cert.js` — грамота (`HeroCert`): за пролог, за Испытание Сбоя на 6 из 6 и за всю главу (`KINDS`, `META`: название, за что, текст печати, значок). Рисуется на canvas 2970 × 2100 (A4 альбомом, 10 точек на мм) — один рисунок и для печати, и для PNG. `content(kind, info)` — тексты и цифры (что пройдено, плашки тем или команд, четыре цифры, дата, подпись), `draw(canvas, c, portrait)` — рисунок (рамка цветов игры, медальон с 3D-портретом Бита и его уровнем, «ГРАМОТА», имя или строка для имени от руки, печать с текстом по кругу), `fonts(wait)` — дождаться шрифтов игры (canvas берёт их у страницы; `true` — все загружены).

## Оформление («тёплый закат»)
- Все цвета — переменные в `:root` в `css/style.css` (день, ночь через `prefers-color-scheme` и `data-theme`): персик `--bg`, фиолет `--accent`, коралл `--coral`, небо `--sky1/--sky-mid/--sky2`, солнце/луна `--sun`, редактор кода `--code*`. Новые цвета — только через них; в 3D те же цвета заданы в материалах `M` и свете (app.js).
- Кнопка «Запуск» объёмная (`--accent-deep` — тень снизу, вдавливается). Анимации героя (`squash`, `dust`, `easeBack`) и звёзд результата (`starPop`) отключаются при `prefers-reduced-motion`.
- Плашка «Проект в стадии тестирования» (`.beta` первым в `<body>`): закреплена сверху над всеми экранами, страница и полноэкранные карточки (`.splash`, `.valley`, `.recap`, `.hp`, `.shots`) начинаются под ней (`--beta-h`); в ролике `?show` и при печати её нет. Новая карточка во весь экран — добавь её класс в это правило.
- «Лёгкая графика» (`#liteBtn`, `save.lite`, класс `body.lite`): без теней, размытия и пыли, пикселей меньше; вместо теней — мягкие пятна под Битом и монетами (`BLOB`, `addBlob`: пятно Бита на `heroRig`, в прыжке меньше, пятна монет — в `blobGroup`, исчезают вместе с монетой); на слабых устройствах (`deviceMemory`/`hardwareConcurrency` ≤ 2) включается сама.
- Ночь: в тёмной теме мир освещён луной (`LOOK.night`, `applyNight` в app.js): свет холоднее и тусклее, земля темнее, монеты, флаг и лава светятся сильнее; в показе (`?show`, `?shots`) мир всегда дневной. Камни по краям дороги низкие (0.12–0.28), чтобы не загораживать карту.
- Металл: карты отражений в сцене нет, поэтому у золота и железа `metalness` не выше 0.2 (иначе темнеют до бурого и чёрного) — блеск даёт солнце, тёплый цвет золота — `emissive`. Так в `M`, на острове героя и в `gear.js`.
- Табличка с числом — спрайт (`signTexture`, место и размер — `SIGN`): всегда повёрнута к камере, стоит справа от Бита и чуть позади, чтобы не закрывать его.
- Живой Бит (app.js, `face`, `animateFace`): моргает, ноги шагают по очереди (`stepFeet`, в прыжке `tuckFeet`), глаза смотрят туда, куда он пойдёт (`glance`: перед поворотом — вбок, датчики world.js несут `look` — `ahead`, `left`, `right`, `down`, `up`), без дела — то на флаг (`face.goal`), то в камеру. Настроение `setMood`: `happy` (победа, верная догадка — глаза «^ ^», улыбка, антенна качается), `sad` (`markFail` — взгляд вниз, рот ∩, антенна никнет, Бит оседает); сбрасывается в `placeHero`. От стены и лавы на полсекунды «> <» (`face.ouch`, галочки `squint`). Глаза не сплющивать: узкие глаза читаются как злость. Подвижные части помнят покой в `userData.rest`: копии героя делаются через `faceRest` (иначе застынут с закрытыми глазами) и моргают через `makeBlinker`; части ищутся по именам (`body`, `head`, `ant`, `bulb`, `eye`, `pupil`), а не по порядку детей. В `?shots` Бит не моргает и смотрит на цель, при `prefers-reduced-motion` — без моргания и покачиваний.
- Облики героя (`HeroGear.SKINS`: `bit` «Классика», `pixel` «Кубик», `iskra` «Ушки»; выбор — `save.gear.skin`, в сводке `D.g.skin`, на странице героя во вкладке «Снаряжение»): `buildHeroParts(skin)` в app.js собирает модель из тех же именованных частей (`body`, `head`, `eyes`, `pupils`, `mouth`, `feet`, `ant`, `bulb`, `ears`, `tail`), поэтому лицо, ноги и антенна двигаются у всех одинаково. `setHeroSkin` пересобирает героя в мире, `makeHeroModel(gear)` — копию для острова, портрета и грамоты (по `gear.skin`). `headDecor` прячет антенну и ушки под шапкой, хвост — под вещью на спину. Новый облик — ветка в `buildHeroParts` и запись в `SKINS` (шапки стоят на высоте головы 0.62, голова не выше 0.84). Кадры для Авито и ролик рисуют классику.
- Кристаллы за достижение летят к кнопке героя (`flyGems`). Кадры для Авито (`poster.js`) и грамота (`cert.js`) рисуют свои цвета в `C` — держи их в той же палитре.

## Правила для новых заданий
- В уроках с условиями карта должна меняться от сида так, чтобы решение «под одну карту» ломалось, а решение с условием работало всегда. В уроках без условий (`basic`) карта одна, нарисованная.
- Стартовый код ломается, `hints[2]` — эталонное решение, `best` — число строк для третьей звезды (или `star3: 'first'` — звезда за решение с первого запуска, если «коротко» даётся даром).
- Типичные неверные решения задания и другие верные варианты перечислены в `tests/check-tasks.js` — дополняй их вместе с заданием. Это касается и заданий со звёздочкой (`bonus`); в разминку (`warmup`) — только задания прошлых уроков.
- Урок строится по образцу Swift Playgrounds: подсказок всё меньше (с 4-го задания над редактором все команды урока — в уроках с условиями это `ALL_CMDS`, стартовый код не подсказывает ответ, финал пишется с нуля). По содержанию сверяемся со школьной программой (Робот в КуМире, ОГЭ): сравнения, `and`/`or`/`not`, `while`.
- Особые карты: `need` — сколько монет нести (больше не взять, ошибка `full`), `stop: true` — победа, только если программа закончилась на флаге (ошибка `stop`), `answer` — что Бит должен сказать командой `сказать()` на флаге (число или `'steps'` — сколько раз шагнул вперёд; ошибка `answer`), `hidden` — флаг не виден и `на_финише()` не работает, `gates` — ворота (`ворота_впереди()`, `открыть()`), `ice` — лёд (`I` в `fromAscii`): шаг или прыжок на лёд — и Бит скользит дальше (`slide` в world.js, события `move` с `slide: true`), пока лёд не кончится или впереди не встанет стена или закрытые ворота; лава на пути не останавливает (ошибка `lava`), `locks` — кодовые замки на воротах (карта клетка → код; такие ворота лежат и в `gates`): `открыть(код)` с числом с таблички, без кода — ошибка `code`, не тот код — `wrongcode`, `levers` — рычаги (карта клетка рычага → клетка ворот; ворота лежат и в `gates`): `дёрнуть_рычаг()` на клетке рычага открывает связанные ворота (события `pull` и `open`, у ворот рычага лампа краснеет и зеленеет), `открыть()` и шаг в такие ворота — ошибка `lever` («замка нет, ищи рычаг»), `дёрнуть_рычаг()` без рычага — `nolever`, `enemies` — дозорные (список `{ path }`, клетки по кругу): после каждого действия Бита (шаг, поворот, взять, открыть, дёрнуть, сказать, `ждать()`) каждый дозорный делает шаг по `path` (`st.tick`, `afterAction` в world.js, события `patrol`, `wait`, `caught`); сначала Бит, потом дозорные, оказались в одной клетке — ошибка `caught`; `враг_впереди()` — дозорный на клетке впереди сейчас или придёт на неё после следующего действия; датчики время не двигают, поэтому `if not враг_впереди(): вперёд()` без `ждать()` — ошибка `loop` с советом про ожидание; генератор карты проверяет, что идти не глядя нельзя, `signs` — таблички с числами (`табличка()` только стоя на ней), `english` — работают только английские имена команд (`EN` в world.js), `broken` — «сломанные» команды, `boss` — Великий Сбой на месте флага. На трёх картах ответ `answer` должен быть разным — иначе угадывается числом.
- Генераторы для карт: `corridor` (отрезки с поворотами), `winding` (случайный путь без касаний), `corners`, `pickLava`, `maze` (лабиринт без петель) и `handWalk` (путь по правилу руки — чтобы класть монеты туда, куда Бит точно зайдёт). У задания `fast` — ускорение анимации (в лабиринтах `fast: 3`).
- Вечный цикл ловится сам: если Бит больше 25 раз оказывается в одном и том же положении (не на флаге), программа останавливается с ошибкой `loop`.
- Новую команду героя добавить в `commands()` (world.js), в `HERO_CMDS` (app.js) для подсветки и, если нужно, анимацию в `animate()`.
- Новый урок — вместе с сюжетом в `js/story.js` (проводник, место, вступление, прощание) и, если нужно, новыми уровнями в `js/gear.js`: последний уровень должен быть достижим звёздами курса.
- Тексты для детей: коротко, на «ты», без канцелярита. Учатся и мальчики, и девочки: к ученику без мужского рода (не «ты прошёл», не «пиши сам» — «весь курс пройден», «пиши с нуля»); это проверяет `tests/check-story.js`.

## Мост к Python
- В каждом уроке 2–3 задания в консоли (минуты 40–55 занятия, см. `PLAN.md`): то же, что ученик делал с Битом, но на обычном Python — `print`, `input`, переменные. Новый урок — вместе с мостом в `js/bridge.js`.
- Задание с вводом проверяется на 3 наборах ответов, ответ на них должен быть разным (тест это проверяет). Стартовый код ломается, типичные ошибки и другие верные решения — в `tests/check-bridge.js`.
