# Долина Эникей

Учебный 3D-тренажёр по Python для начинающих с 12 лет — инструмент репетитора.
Ребёнок пишет настоящий код, а герой выполняет его в трёхмерном мире.
Концепция, сценарий занятия и план развития — в [`PLAN.md`](PLAN.md).

**Курс** — уроки по 8 заданий, подсказок от задания к заданию всё меньше, последнее пишется с нуля:

1. **Команды** — последовательность команд, повороты, монеты, прыжки. Это пробный урок для новичка.
2. **Циклы** — `for`: повтор команд, два цикла подряд.
3. **Условия** — `if`, `if / else`, `elif`, сравнения и `and`, `while not`. С этого урока каждое решение проверяется на трёх случайных картах, поэтому без условий не обойтись.

В уроках 1–2 у задания одна нарисованная карта.

**Сюжет и прокачка.** Долину сломал Великий Сбой, и робот Бит чинит её кодом ученика. Каждый урок — квест со своим проводником: Ада, горное Эхо, Сова Развилка. За звёзды Бит получает уровни и снаряжение — шарф, рюкзак, шляпу, плащ, светлячка, корону, — которое видно на нём в 3D.

## Запуск

Откройте `index.html` в браузере. Сервер и интернет не нужны.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `css/style.css` | оформление |
| `js/world.js` | мир: команды героя, карты, список уроков |
| `js/lessons/` | **уроки**: по файлу на урок, в каждом задания и карты |
| `js/minipy.js` | учебный Python: выполнение по шагам, ошибки на русском |
| `js/app.js` | интерфейс, 3D-сцена, анимации, звёзды и подсказки |
| `js/story.js` | сюжет: робот Бит, проводники уроков и их реплики |
| `js/gear.js` | прокачка: уровни героя и снаряжение |
| `js/three.min.js` | 3D-библиотека three.js r128 (MIT) |

Как менять и добавлять задания и уроки — в `README.txt`.
