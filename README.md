# Долина Эникей

Учебный 3D-тренажёр по программированию на Python для школьников 5–8 классов.
Ребёнок пишет настоящий код, а герой выполняет его в трёхмерном мире.
Каждое решение проверяется на трёх случайных картах, поэтому без условий не обойтись.

**Урок «Условия»:** восемь заданий, подсказок от задания к заданию всё меньше.

1. «Монеты вразброс» — `if` в цикле.
2. «Стена за углом» — проверка перед шагом.
3. «Через лаву» — `if / else`.
4. «Почини программу» — найти ошибку в отступе в чужом коде.
5. «Стена, лава или путь» — `elif`, выбор из трёх.
6. «Рюкзак на три монеты» — сравнение чисел и `and`.
7. «Стоп на флаге» — `while not`.
8. «Всё вместе» — программа с нуля на смешанной карте.

## Тест «Коллекции в Python»

Отдельная страница `python-collections-test/` — 25 вопросов про списки, кортежи, словари и множества.
На сайте: `https://<ваш-логин>.github.io/<имя-репозитория>/python-collections-test/`.
Правильность видна только после ответа на все вопросы и кнопки «Сдать»; варианты ответов при каждом прохождении перемешиваются.
Вопросы и ключ ответов — в `python-collections-test/questions.js`, после правок запустите `node tests/check-quiz.js`.

## Запуск

Откройте `index.html` в браузере. Сервер и интернет не нужны.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `css/style.css` | оформление |
| `js/world.js` | **задания**, карты и команды героя |
| `js/minipy.js` | учебный Python: выполнение по шагам, ошибки на русском |
| `js/app.js` | интерфейс, 3D-сцена, анимации, звёзды и подсказки |
| `js/three.min.js` | 3D-библиотека three.js r128 (MIT) |
| `python-collections-test/` | тест «Коллекции в Python»: `index.html` и вопросы `questions.js` |
| `js/quiz.js`, `css/quiz.css` | движок и оформление тестов |

Как менять и добавлять задания — в `README.txt`.
