ДОЛИНА ЭНИКЕЙ — Python с нуля (локальная версия)

КАК ЗАПУСТИТЬ
Распакуйте архив и дважды щёлкните index.html. Страница откроется в браузере.
Интернет не нужен: 3D-библиотека лежит в папке js. Без интернета просто
подставятся системные шрифты вместо фирменных.
Лучше всего работает в Chrome, Edge или Firefox.

ЧТО В ПАПКЕ
index.html        — каркас страницы
css/style.css     — оформление: цвета, шрифты, раскладка
js/three.min.js   — 3D-библиотека three.js (не трогать)
js/minipy.js      — учебный Python: разбирает и выполняет код ученика,
                    выдаёт ошибки на русском
js/world.js       — мир: команды героя, карты, список уроков
js/lessons/       — УРОКИ: по файлу на урок, в каждом задания и карты
js/app.js         — интерфейс, 3D-сцена, анимации, звёзды, подсказки
PLAN.md           — концепция, сценарий занятия и план развития
js/quiz.js, css/quiz.css — движок и оформление тестов
python-collections-test/ — тест «Коллекции в Python» (страница и вопросы)

УРОКИ (по 8 заданий)
1 Команды (js/lessons/1-komandy.js) — последовательность, пробный урок
2 Циклы   (js/lessons/2-cikly.js)   — for
3 Условия (js/lessons/3-usloviya.js) — if, else, elif, and, while not
Урок выбирается в шапке сайта. С 4-го задания урока над редактором все
команды, стартовый код не подсказывает ответ, а в финале код пишется с нуля.
В уроках 1–2 у задания одна нарисованная карта, с урока 3 — три случайные.

ЧТО МОЖНО МЕНЯТЬ БЕЗ ПРОГРАММИРОВАНИЯ
Всё про задания лежит в файлах js/lessons/, в списке tasks. У каждого задания:
  title    — название
  goal     — что нужно сделать
  news     — что нового в этом задании
  cmds     — команды-подсказки над редактором (ALL_CMDS — все команды)
  starter  — стартовый код (\n — перенос строки, 4 пробела — отступ)
  hints    — две подсказки и готовое решение
  best     — сколько строк нужно, чтобы получить третью звезду
  star3    — за что третья звезда: по умолчанию «коротко» (не длиннее best),
             'first' — «сработало с первого запуска» (запуск нетронутого
             стартового кода и проверки кнопкой «Шаг» не считаются)
  map      — нарисованная карта (уроки 1–2), см. ниже
  gen      — генератор случайных карт (с урока 3)

НАРИСОВАННАЯ КАРТА (map)
Каждая строка — ряд клеток, сверху — север. Знаки:
  .  пол        $  монета      ~  лава        F  флаг
  > ^ < v  старт: откуда начинает герой и куда смотрит
  пробел или #  стена
Пример — дорога с поворотом налево:
  map: [
    '  F',
    '  .',
    '>..',
  ],

КАК ДОБАВИТЬ ЗАДАНИЕ
1. В урок без условий (1–2) — нарисуйте карту в поле map.
   В урок с условиями — напишите функцию-генератор карты по образцу
   genCoins, genTurn или genLava в файле урока: клетки пола, лава, монеты,
   старт и финиш. Коридор с поворотами удобно строить функцией corridor,
   лаву на нём расставлять функцией pickLava. У карты можно задать need —
   сколько монет нужно принести (больше взять нельзя), и stop: true — флаг
   засчитывается, только если программа закончилась на нём.
2. Добавьте в список tasks урока новый объект по образцу существующих.
   id задания должен быть уникальным во всём курсе.
3. Если нужна новая команда героя, добавьте её в функцию commands
   (в world.js) и её имя в список HERO_CMDS (в app.js) для подсветки.
Вкладка с новым заданием появится сама. Проверьте: node tests/check-tasks.js

КАК ДОБАВИТЬ УРОК
1. Скопируйте файл урока в js/lessons/ с новым номером, например
   4-poka.js, и поменяйте id, title, intro и задания. basic: true — урок
   без условий: одна карта, в сообщениях об ошибках нет советов про if.
2. Подключите файл в index.html рядом с остальными уроками, по порядку.
Урок появится в списке в шапке сайта.

ТЕСТ «КОЛЛЕКЦИИ В PYTHON»
Отдельная страница: папка python-collections-test, файл index.html
(на сайте — адрес сайта + /python-collections-test/). 25 вопросов; что верно,
видно только после ответа на все вопросы и кнопки «Сдать». Варианты ответов
каждый раз перемешиваются.
Вопросы, ответы и пояснения — в python-collections-test/questions.js:
  type     — one (один ответ), many (несколько), match (сопоставление)
  answer   — буквы верных вариантов по порядку в файле: 'Б', 'АВГ';
             для match — буква из right для каждой строки left: 'БГДВА'
  explain  — пояснение после сдачи (без ссылок на буквы — их перемешивают)
  grades   — оценка по числу верных ответов
После правок проверьте: node tests/check-quiz.js
Новый тест: скопируйте папку python-collections-test под другим именем
и поменяйте в questions.js id, title и вопросы.

КАК СБРОСИТЬ ПРОГРЕСС УЧЕНИКА
Код, звёзды и подсказки хранятся в браузере. Чтобы начать с нуля, откройте
в браузере инструменты разработчика (F12) → Application/Хранилище →
Local Storage и удалите запись mir-geroya-usloviya-v1.

УДОБНОЕ РЕДАКТИРОВАНИЕ
Откройте папку в VS Code. Расширение Live Server обновляет страницу
сразу после сохранения файла.
