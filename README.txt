ДОЛИНА ЭНИКЕЙ — урок «Условия» (локальная версия)

КАК ЗАПУСТИТЬ
Распакуйте архив и дважды щёлкните index.html. Страница откроется в браузере.
Интернет не нужен: 3D-библиотека лежит в папке js. Без интернета просто
подставятся системные шрифты вместо фирменных.
Лучше всего работает в Chrome, Edge или Firefox.

ЧТО В ПАПКЕ
index.html        — каркас страницы
css/style.css     — оформление: цвета, шрифты, раскладка
js/three.min.js   — 3D-библиотека three.js (не трогать)
js/minipy.js      — учебный Python: разбирает и выполняет код ученика,
                    выдаёт ошибки на русском
js/world.js       — мир: команды героя, генераторы карт и СПИСОК ЗАДАНИЙ
js/app.js         — интерфейс, 3D-сцена, анимации, звёзды, подсказки

ЧТО МОЖНО МЕНЯТЬ БЕЗ ПРОГРАММИРОВАНИЯ
Всё про задания лежит в js/world.js, в массиве TASKS. У каждого задания:
  title    — название
  goal     — что нужно сделать
  news     — что нового в этом задании
  cmds     — команды-подсказки над редактором
  starter  — стартовый код (\n — перенос строки, 4 пробела — отступ)
  hints    — две подсказки и готовое решение
  best     — сколько строк нужно, чтобы получить третью звезду
  star3    — за что третья звезда: по умолчанию «коротко» (не длиннее best),
             'first' — «сработало с первого запуска» (запуск нетронутого
             стартового кода и проверки кнопкой «Шаг» не считаются)
  gen      — какая карта генерируется

КАК ДОБАВИТЬ ЗАДАНИЕ
1. В js/world.js напишите функцию-генератор карты по образцу genCoins,
   genTurn или genLava: укажите клетки пола, лаву, монеты, старт и финиш.
2. Добавьте в массив TASKS новый объект по образцу существующих.
3. Если нужна новая команда героя, добавьте её в функцию commands
   (в world.js) и её имя в список HERO_CMDS (в app.js) для подсветки.
Вкладка с новым заданием появится сама.

КАК СБРОСИТЬ ПРОГРЕСС УЧЕНИКА
Код, звёзды и подсказки хранятся в браузере. Чтобы начать с нуля, откройте
в браузере инструменты разработчика (F12) → Application/Хранилище →
Local Storage и удалите запись mir-geroya-usloviya-v1.

УДОБНОЕ РЕДАКТИРОВАНИЕ
Откройте папку в VS Code. Расширение Live Server обновляет страницу
сразу после сохранения файла.
